Technical Requirements

# Development environment
- Teams must use Velocity 2.0.
- Local demonstrations are accepted.
- The committee will not provide a separate hosted environment for every solution.
- Teams may use approved simulated services, connectors and MCP servers.
- Each team must confirm its required licenses before development begins.
- API and model consumption must remain within the assigned budget.
- Teams must not rely on a free trial without reviewing renewal and cancellation terms.

# Security and data
- Do not store credentials, tokens or keys in the repository.
- Include an example environment file with required variable names.
- Use synthetic or anonymized data unless the committee provides written approval.
- Do not connect to client production environments.
- Require human approval for sensitive or irreversible actions.
- Document prohibited actions and failure conditions.
