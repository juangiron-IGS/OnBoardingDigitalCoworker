## 1. Technical Overview

### 1.1 System Context
The Onboarding Digital Coworker is a set of AI agents that run on Velocity 2.0 and support INSPYR's consultant onboarding process: intake and validation of the start email or chat, path and paperwork recommendation, approval package, approval gate and simulated actions. It is a greenfield project with no prior release.

The target deployment is a local demo on localhost with synthetic data and simulated enterprise systems. It is built by a six-person hackathon team for the October 28, 2026 submission. The architecture is a lightweight local web app talking to an Onboarding Orchestrator, which routes each case to specialized agents on one shared context. Details are in §2 and §6.

### 1.2 Current Technical Landscape
Not applicable as an increment or replacement. The surrounding enterprise systems (JobDiva, Outlook onboarding mailbox, Chelsea Tech, Paychex, the LDC tracker, the onboarding knowledge base and Microsoft Teams) are represented by mocks for the demo (see INF-003).

#### QA-001 Functional Suitability — Key Architectural Answers

#### QA-003 Compatibility / Interoperability — Key Architectural Answers

| Question | Answer | Source |
|----------|--------|--------|
| Which external systems must this integrate with? | Velocity 2.0 (real and mandatory: agent runtime, orchestration and models). #### QA-006 Security — Key Architectural Answers
